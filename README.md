# Student Record and Expense Tracker 📊

A console-based Python application designed to manage student personal records, calculate academic performance metrics, and track monthly student expenses efficiently.

## 🚀 Features
- **Student Profile Management:** Stores student core information including Name and Age.
- **Academic Performance Analyzer:** 
  - Computes total and average marks from user-defined subjects.
  - Dynamically identifies the **Maximum** and **Minimum** marks scored.
  - Categorizes student performance rank (e.g., *Excellent*, *Very Good*, *Average*, *Needs Improvement*) using custom function logic.
- **Expense Tracker:** Tracks and sums up categorized daily/monthly student living costs such as Food, Transport, Study, and other miscellaneous expenses.
- **Structured Data Logging:** Utilizes Python dictionaries to consolidate all data into a clean, readable student profile summary.

## 🛠️ Tech Stack & Concepts Used
- **Language:** Python 3
- **Control Flow:** Conditional Statements (`if-elif-else`), Loops (`while`, `for`)
- **Data Structures:** Lists (for marks management), Dictionaries (for expense categories and final record mapping)
- **Modular Programming:** Custom Python functions with return statements for grade analysis.

## 💻 How to Run
1. Clone this repository or download the source code file.
2. Open your terminal or an IDE (like VS Code).
3. Run the script using:
   ```bash
   python student_record.py
   ```
4. Follow the on-screen console prompts to enter student details, academic marks, and expense breakdown.
